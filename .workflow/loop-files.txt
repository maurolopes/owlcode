# The loop's files: the paths that a product copies from this repository at its pinned commit (README.md "How a product
# uses the loop"). One path or glob a line, relative to the repository's root; a folder names every file beneath it
# (hidden ones too); `*` and `**` skip a name that starts with a dot, so a hidden folder or file has its own line; a line
# that starts with `!` takes files out. .github/leak_guard.py reads this list (`mise run leak:count`). Each repository's
# own files stay out: its code, its own skills, its documents (AGENTS.md, DECISIONS.md, README.md), its guards
# (.github/CODEOWNERS), its own workflows (its gates, its caches) with their scripts, and its own tests. The loop's tests
# check only the loop's workflows (tests/test_ci.py `product_workflows`): a repository checks its own workflows in its
# own tests.
